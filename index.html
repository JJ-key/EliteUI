About

A cross-platform UI library for Roblox — PC, Mobile & Tablet

EliteUI is a modern UI library built for Roblox scripts. It features a sharp purple theme, smooth animations, and a simple API that works seamlessly on PC keyboards, mobile touchscreens, and tablets.

PC Support

Full keyboard navigation. RightShift toggles the UI. Drag-to-move window.

Mobile & Touch

Hold 3 fingers for 0.8 s to toggle. Touch-friendly 44 px tap targets throughout.

Purple & Black Theme

Sleek dark design with a customisable accent colour and smooth tweened animations.

Settings Persistence

JSON-based settings saving and a built-in Default Settings Tab. No extra setup.

Tabs & Sub-tabs

Organise your features with nested tabs and auto-generated section headers.

Simple API

One-line loadstring loader. Methods for buttons, toggles, sliders, dropdowns, and more.

Installation

Load EliteUI in your Roblox script

Paste the following line at the top of your script. Works on PC executors and mobile injectors.

Components

Interactive UI elements with live previews and copy-ready Lua code

Window

The main container. Creates a draggable window with tabs. Supports an optional Key System, Snow Effect, and per-device UI scaling.

Lua
local Window = EliteUI:CreateWindow({
    Name = "My Script Hub",
    LoadingTitle = "Loading...",
    Subtitle = "v1.0",
    ToggleKey = Enum.KeyCode.RightShift,  -- PC toggle key

    -- Per-device scaling
    UIScale = {
        PC = 1.0,
        Mobile = 0.85,
        Tablet = 0.9
    },

    -- Key System (optional)
    KeySystem = {
        Enabled = true,
        URL = "https://pastebin.com/raw/YOURKEY",
        Title = "Key Required",
        Subtitle = "Enter your key to continue",
        NoteName = "Get Key",
        NoteURL = "https://yoursite.com/getkey",
        SaveKey = true,
        FileName = "key.txt"
    },

    -- Snow Effect (optional)
    SnowEffect = {
        Enabled = true,
        ParticleCount = 50,
        Speed = 1,
        Glow = true
    }
})

Tab

Top-level navigation tabs. Pass an icon name from the built-in Lucide icon set.

Lua
local MainTab     = Window:CreateTab("Main",     "home")
local SettingsTab = Window:CreateTab("Settings", "settings")

Sub-Tab

Nested tabs within a main tab for deeper organisation.

Lua
local CombatTab = Window:CreateTab("Combat", "sword")
local SubTabs   = CombatTab:CreateSubTab({"Aimlock", "Camlock", "Triggerbot"})

SubTabs["Aimlock"]:CreateSection("Aimlock Settings")
SubTabs["Aimlock"]:CreateToggle({
    Name = "Enable Aimlock",
    CurrentValue = false,
    Callback = function(Value)
        print("Aimlock:", Value)
    end
})

SubTabs["Camlock"]:CreateSection("Camlock Settings")
SubTabs["Camlock"]:CreateDropdown({
    Name = "Target Part",
    Options = {"Head", "Torso", "HumanoidRootPart"},
    CurrentValue = "Head",
    Callback = function(Option)
        print("Target:", Option)
    end
})

Invisible Button

A draggable floating button — ideal for mobile actions. Invisible when UI is closed, visible when open. Supports custom images.

Lua — Basic
local InvisibleBtn = Window:CreateInvisibleButton({
    Size = 50,
    TapCount = 3,
    SavePosition = true
})
Lua — With Image & Callback
local InvisibleBtn = Window:CreateInvisibleButton({
    Size = 50,
    TapCount = 3,
    SavePosition = true,
    Image = "rbxassetid://123456789",
    Callback = function()
        Window:Toggle()
    end
})

InvisibleBtn:SetImage("star")     -- update icon
InvisibleBtn:SetSize(60)
InvisibleBtn:SetPosition(0.5, 0.1)
InvisibleBtn:SetTapCount(2)
InvisibleBtn:Destroy()

Default Settings Tab

Auto-generates a complete Settings tab — theme picker, scale slider, size presets, notifications, and version info.

Lua — One-liner
local SettingsTab = Window:CreateDefaultSettingsTab()
Lua — Custom Options
local SettingsTab = Window:CreateDefaultSettingsTab({
    TabName = "Settings",
    TabIcon = "settings",
    ShowThemeCustomization = true,
    ShowUIScale = true,
    ShowUISizePresets = true,
    ShowNotifications = true,
    ShowDataManagement = false,
    ShowControls = true,
    ShowInfo = true,
    Version = "1.0.0",
    AboutText = "My custom script.",
    CustomThemePresets = {
        ["Ocean"] = Color3.fromRGB(6, 182, 212),
        ["Forest"] = Color3.fromRGB(34, 197, 94)
    }
})

-- Add custom elements to the generated tab
SettingsTab:CreateSection("My Settings")
SettingsTab:CreateToggle({
    Name = "Debug Mode",
    CurrentValue = false,
    Callback = function(Value) print("Debug:", Value) end
})

Example Script

Full universal script — PC & Mobile compatible

EliteUI v3.7.0 — Universal Script 
-- EliteUI v3.7.0 Universal Script
-- PC & Mobile compatible

local EliteUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/JJ-key/EliteUI/main/Loader"))()

-- Services
local Players          = game:GetService("Players")
local RunService       = game:GetService("RunService")
local UserInputService = game:GetService("UserInputService")
local Workspace        = game:GetService("Workspace")
local Lighting         = game:GetService("Lighting")
local TeleportService  = game:GetService("TeleportService")

local LocalPlayer = Players.LocalPlayer
local Camera      = Workspace.CurrentCamera

-- Helper functions defined before use
local function getCharacter()
    return LocalPlayer.Character or LocalPlayer.CharacterAdded:Wait()
end

local function getHumanoid()
    local char = getCharacter()
    return char and char:FindFirstChildOfClass("Humanoid")
end

local function getRootPart()
    local char = getCharacter()
    return char and (char:FindFirstChild("HumanoidRootPart") or char:FindFirstChild("Torso"))
end
